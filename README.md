# RenTech Pipeline

BAT 405 - BSIT 4A Analytics Application

This project is about creating a data pipeline for RenTech, a Rental Management System with Demand Forecasting for Mylene's Boutique.

The pipeline prepares clean rental data for forecasting. Work is divided into documentation, GitHub issues, and coding.
